## CSS Architecture

The CSS is separated into three stylesheets:

### base.css

Shared stylesheet containing:

- colour palette
- typography
- header
- navigation
- main
- footer
- shared components
- common table/form styles

### saparkhan.css

Personal stylesheet for:

- Home
- Services
- Colophon

### turarbek.css

Personal stylesheet for:

- Orthodontics
- Medical Team
- Contacts

Each HTML page loads:

1. `base.css`
2. personal stylesheet
