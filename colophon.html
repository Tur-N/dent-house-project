PROJECT OVERVIEW

Project Overview & Collaboration Architecture

Dent house Dental Clinic is the project theme for Group SE-2531. The website contains six connected HTML pages and uses Bootstrap for its main layout, responsive grid and common interface elements.

Student Responsibilities

  • Saparkhan Shyngyskhan: Home, Services, Colophon and css/saparkhan.css.
  • Turarbek Nurakhmet: Orthodontics, Medical Team, Contacts and css/turarbek.css.

Semantic HTML

The pages use semantic elements such as header, nav, main, section, article, figure, table, form and footer to describe the content structure.

CSS Architecture

Bootstrap handles most layout, navigation, spacing, tables and form controls. The three custom stylesheets provide shared colours and typography, page-specific decoration and small responsive corrections.

Future JavaScript

The booking form, its controls, the navigation toggler and message containers have stable IDs. The form is still a prototype and does not contact a booking system.

Technologies

  • HTML5 semantic structure
  • CSS3 variables and animations
  • Bootstrap 5.3.8
  • Bootstrap Grid and responsive breakpoints
  • Bootstrap tables, forms and navbar

Validation

Before submission, each HTML page and CSS stylesheet must be tested with the W3C validators. The target is zero validation errors. Actual validation results must be recorded after the checks are completed.
