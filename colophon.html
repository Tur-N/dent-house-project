Project Overview & Collaboration Architecture

Dent house Dental Clinic is the fixed project theme for Group SE-2531. The site is a local-file HTML/CSS project using Bootstrap for responsive design and layout.

SEMANTIC HTML

Structure

The project uses header, nav, main, section, article, address, figure, table, form, fieldset, legend, label and footer where they communicate the role of the content.

CSS ARCHITECTURE

Stylesheet Cascade

Bootstrap now handles most layout, spacing, navigation, typography, buttons and responsive behaviour. The custom CSS files provide only colours, fonts, animation and small corrections.

VALIDATION

Technical Compliance

Before submission, every HTML document should be checked with the W3C HTML validator and every stylesheet should be checked with the W3C CSS validator. The target is zero validator errors.
