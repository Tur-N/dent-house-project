Semantic Tag Rationale

In accordance with Assignment 1 requirements, non-semantic <div> tags were systematically replaced with explicit HTML5 structural elements:

  • <header> and <nav> structure the persistent header and global navigation menu.
  • <main> encloses primary page content, partitioned logically into <section> and <article> components.
  • <address> encapsulates contact phone numbers and geographical location for search engine indexing.
  • <table> elements structure medical pricing using <caption>, <thead>, <tbody>, and <th scope="col"> for accessibility.
  • <form> structures appointment booking using <fieldset>, <legend>, and explicit <label> associations.
